# Original review artwork

The eight `vector-v2/` SVGs are original geometric illustrations authored in
`scripts/generate-public-art.mjs`, licensed under the root MIT license. Run
`node scripts/generate-public-art.mjs` from the repository root to reproduce them.
No reference images, external fonts, book covers, or bitmap tracings are inputs.

Known retired concept/ink/fantasy-preview references resolve to these vectors
at presentation time; saved facts and identity choices are unchanged.
Original achievement seals in `src/reviews/achievement-art.ts` remain MIT.
