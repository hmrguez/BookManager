# Wovenleaf website

Static Astro site for the free, open-source application. Download/source links
point to the public repository and community-build instructions. The site does
not promise an existing store listing, hosted app or prebuilt release.

```sh
bun install --frozen-lockfile
bun run dev
bun run lint
bun run typecheck
bun run build
```

Output is `dist/`; it can be served by any static host. The existing deployment
configuration is optional. Configure operator/contact details in `src/legal.ts`
for your own fork before publishing privacy and terms pages.

`public/illustrations/` contains original geometric illustrations, fictional books
and original text generated by `node ../../scripts/generate-public-art.mjs`.
These are illustrative previews, not device screenshots. No commercial book covers,
external fonts, downloaded EPUB text or service logos are inputs. The site bundles
its Fontsource fonts and dependency notices under `public/licenses/`.
