# Optional Google Play artwork

No historical screenshot/export package is redistributed. Build your own release
and capture it with fictional data and original cover fixtures. The canonical
project identity is in `branding/source/`; platform icon generation is described
in the root branding README. Landing illustrations are original MIT artwork but
are illustrations, not evidence of actual device behavior.

No Play billing product, verification key or paid contract is needed by this app.
Android APK distribution without Play is documented in
`docs/guides/community-builds.md`. Store publication remains optional.
